# 勤怠・残業時間計算プログラム
Pythonで作成しました。
1日の勤怠時間、残業時間を計算するためのプログラムです。

## 主な機能
- 出退勤・休憩時間入力することによってその日の実働時間を計算、表示することが出来ます。
- 実働時間から既定の労働時間を差し引いた残業時間を計算、表示することが出来ます。
- 入力形式の違う文字が入った場合には起動しなおさずに再度入力をすることが出来ます。

## 使い方
1. プログラム起動
2. 出勤時間(時)の入力
3. 出勤時間(分)の入力
4. 退勤時間(時)の入力
5. 退勤時間(分)の入力
6. 休憩時間(分)の入力
エラーが出た際には再度表示された内容に従って入力を行ってください。

## 制限事項
- 日を跨ぐ時間計算には対応していません。
- 既定の労働時間は8時間としています。
